# YOUTWEET

YOUTWEET is a native Android short-video social platform.

## Planned Features

- TikTok-style vertical short-video feed
- User accounts and profiles
- Video upload and sharing
- Likes, views, and comments
- Followers and following
- Firebase metadata database
- Google Drive video storage integration
- Dark modern user interface

## Technology

- Kotlin
- Android
- Firebase
- Google Drive API
- Media3 ExoPlayer

## Project Status

The application is currently under development.
